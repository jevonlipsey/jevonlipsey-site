Ubiquitous computing game designed to highlight ocean plastic pollution. Implements dual-input multimodal controls: players steer a boat via a physical BBC Micro:bit connected over the Web API while using Google MediaPipe computer vision to track hand-grab gestures via webcam to haul floating debris out of the Three.js scene.
